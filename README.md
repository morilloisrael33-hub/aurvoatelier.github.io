> **"Elegancia Atemporal. Hecho en Perú."**

Bienvenido al repositorio oficial de la plataforma digital de **Aureum Atelier**, una marca de moda de alta costura que redefine el lujo en Lima con una estética minimalista, oscura y sofisticada.

## 🎨 Concepto de Diseño

El sitio web ha sido diseñado siguiendo los principios de **"Dark Luxury"**:
* **Paleta de Colores:** Fondo Negro Profundo (`#050505`) con acentos en Oro Metálico (`#D4AF37`).
* **Tipografía:** *Playfair Display* para títulos editoriales y *Montserrat* para una legibilidad moderna.
* **UI/UX:** Uso de *Glassmorphism* (efectos de cristal) en la navegación y animaciones suaves al hacer scroll.

## 🚀 Características Técnicas

Este proyecto no es solo estético, está construido sobre estándares de **Clean Code**:

* **HTML5 Semántico:** Estructura optimizada para SEO.
* **CSS3 Moderno:** Uso de Variables CSS (`:root`) para consistencia de marca y mantenibilidad.
* **JavaScript Vanilla:** Sin dependencias pesadas, garantizando una carga ultra rápida.
* **PWA Ready:** Estructura preparada con `manifest.json` para ser instalada como App en móviles.
* **Responsive Design:** Adaptación fluida desde móviles hasta pantallas 4K.

## 🛠️ Instalación y Despliegue

### Requisitos
* Navegador Web Moderno (Chrome, Edge, Safari).
* Git (para control de versiones).

### Visualización Local
Para ver el proyecto en tu máquina local:

1.  Clona el repositorio:
    ```bash
    git clone [https://github.com/TU_USUARIO/aureum-atelier.git](https://github.com/TU_USUARIO/aureum-atelier.git)
    ```
2.  Navega a la carpeta del proyecto.
3.  Abre el archivo `index.html` en tu navegador.
